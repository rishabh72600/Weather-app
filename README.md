Weather App

A simple and responsive Weather App that provides real-time weather information for any city worldwide. Built using HTML, CSS, and JavaScript, this app fetches data from the OpenWeatherMap API and displays temperature, humidity, wind speed, and weather conditions in a user-friendly interface.

## Features

- Search for weather information by city name
- Real-time weather data using OpenWeatherMap API
- Displays:
  - Current temperature
  - Weather conditions (e.g., cloudy, sunny, rainy)
  - Humidity
  - Wind speed
- Responsive and minimalist design
- Error handling for invalid city names

## Setup Instructions

1. Clone the repository:
   ```bash

2. Open index.html in your browser.


3. To use the app with your own API key:

Go to OpenWeatherMap and generate a free API key.

Replace the existing API key in the JavaScript file (script.js) with your key:

const apiKey = "YOUR_API_KEY";
